## 4. SAB 启动探针

`npm start` 运行 7 秒，应用窗口、信令 server 和 renderer 均成功启动。任务书指定的主进程探针输出：

```text
[syncplay-init] {
  "electron": "38.8.6",
  "chrome": "140.0.7339.249",
  "node": "22.22.0",
  "sab": true,
  "webcodecs": false
}
```

补充说明：`VideoDecoder` 是 Chromium renderer Web API，不是 Electron Node 主进程全局，因此主进程里的 `webcodecs: false` 不代表 Chromium 不支持 WebCodecs。首次通过运行中 Electron renderer 观测时发现 `crossOriginIsolated: false`、SAB 不可用；按照执行计划 §5 的兜底方案，在 `session.defaultSession.webRequest.onHeadersReceived` 中加入 COOP/COEP：

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

修复后同时验证 dev 与打包后的 `.app` renderer，结果均为：

```json
{
  "crossOriginIsolated": true,
  "sab": true,
  "webcodecs": true,
  "mediaSource": true,
  "peerjs": true
}
```

- SharedArrayBuffer / WebCodecs / MediaSource: renderer 全部可用
- PeerJS CDN 脚本在 COEP 下仍成功加载，主界面“创建房间”按钮正常渲染
- Ctrl-C 后端口 9000 正常释放，无残留信令进程
- 最终打包运行截图: `/tmp/syncplay-v0.7-B-A-packaged-sab-runtime.png`（本地验证证据，不入库）
