### 改动

### 新段内容 (段级 highlights)

```
## 🎬 支持的视频格式 (v0.7 新增)

| 容器 | codec | 路径 | 硬解 |
|------|-------|------|------|
| mp4  | H.264/H.265/AV1 | 原生 <video> | ✅ M-series VideoToolbox |
| webm | VP8/VP9/AV1    | 原生 <video> | ✅ AV1 on M1+/RTX 30+ |
| m3u8 | H.264/H.265/AAC | hls.js → MSE | ✅ hls.js 内置 |
| mkv  | H.264/H.265/VP9 | ffmpeg.wasm → fMP4 → MSE | ✅ VideoToolbox |
| avi/flv/mov/wmv | mixed | ffmpeg.wasm → fMP4 → MSE | 软解 / mov 原生硬解 |

决策树 (per loadVideo() 的 4-branch 判定)
已知限制 (4 项: 字幕 MVP-drop / 大文件 2GB / 软编 fallback MVP-drop / URL 后缀判定)
快速验证命令 (启动 dev + 选视频 + chrome://gpu 检查)
```

### 位置理由

- 在 `📦 安装包下载` 之后 — 自然 flow: install → 看支持格式 → quick start
- 在 `🚀 快速开始` 之前 — 支持格式是 quick start 的前置上下文
- 不在 `⚠️ 已知限制` 段 (避免与已知限制混淆) — 用表格 + 单独"已知限制 (v0.7 MVP)"小节
