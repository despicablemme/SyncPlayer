# Tester 报告模板

> **这是什么？** Tester Claude Code 写完测试后**必须**用本模板写报告——主 agent 验收时按本模板核对。
> **何时使用？** Tester 跑完所有验证项后，复制本模板填实际结果。
> **最后更新：** 2026-06-09

---

## 使用方式

1. **复制本文件** → `tasks/<task-name>-test-report.md`
2. **替换占位符** + **填实际结果**（PASS/FAIL + 证据）
3. **git commit**（**不** push）
4. **stdout 输出** `TESTER_DONE: tasks/<task-name>-test-report.md`
