## 给 Builder 的修复建议

**无必须修复项.** 3 个 ⚠️ note 都不是 bug, 列在这里供 Builder 知情:

1. **8.1 (dev 模式 userData 路径)**: 当前是 Electron 行为, Builder 实现正确. 如果想让 dev 模式也用 `SyncPlay/` 目录方便测试, 可在 main.js 顶部加 `if (!app.isPackaged) app.setName('SyncPlay');`. 但这是**可选的**, 改了反而会让 dev 调试跟生产环境行为不一致. 建议**不改**.

2. **8.3 (文件权限 0o666)**: 当前 0o666, 比 644/600 更宽松. Preferences 目录默认就是 0o666 (因为 macOS 的 `chmod g+w` 默认开启), 实际可读可写, 不影响功能. 如果有合规要求, 可在 main.js `app.whenReady` 里加 `try { fs.chmodSync(videoHistoryStore.path, 0o600); } catch(e) {}`. 建议**不改**, 0o666 是 macOS 习惯.

3. **1.3 (electron-store 8.x 无 main/exports)**: 8.x 是 CommonJS 时代的设计, 依赖 Node 默认 `index.js` 解析. 9.x 起改成 ESM + exports. 8.x 的选择**合理** (跟 main.js `const Store = require('electron-store')` 兼容), 不需要改.
