# SyncPlay 架构详解

> v2 架构说明（2026-06-06 重构后）

---

## 总体架构

```
┌─────────────┐                              ┌─────────────┐
│   用户 A     │                              │   用户 B     │
│  (浏览器)    │                              │  (浏览器)    │
│             │                              │             │
│  本地视频   │                              │  本地视频   │
│      ↕      │                              │      ↕      │
│  HTML5 <video>                              │  HTML5 <video>
│      ↕      │                              │      ↕      │
│  SyncEngine │◄──────► WebRTC DataChannel ◄►│  SyncEngine │
│      ↕      │      (play/pause/seek/...)   │      ↕      │
│  PeerJS     │                              │  PeerJS     │
│   Client    │                              │   Client    │
└──────┬──────┘                              └──────┬──────┘
       │                                            │
       │   信令（仅建立 P2P 连接，不传视频）         │
       │                                            │
       └──────────────┬─────────────────────────────┘
                      ▼
            ┌─────────────────────┐
            │  PeerJS 信令服务器   │
            │  (公共或自建)        │
            └─────────────────────┘
```

**关键原则**：
- 视频文件**永远不上传**
- 同步指令**只走 P2P**（不经过服务器）
- 信令服务器**只负责建立连接**

## 同步引擎核心（`client/app.js`）

### 状态机

```
                    ┌──────────────┐
   本地点击 ─────►  │              │  ──►  send(msg)
                    │   SyncEngine │
   远端消息 ─────►  │              │  ──►  video.currentTime / play / pause
                    └──────────────┘
                           │
                  guardUntil 时间戳
                  （屏蔽 200ms 内本地事件）
```

**关键设计**：
- 用 `guardUntil` 时间戳**标记屏蔽窗口**（替代 v1 的 50ms 定时器）
- 仅当**位置偏差 > 0.3s** 时才校正（避免微小抖动）
- 心跳 5s 一次，漂移检查 10s 一次

### 漂移校准

```
A 端                                         B 端
  │                                            │
  │  drift_check { remotePosition: 12.5 }       │
  ├──────────────────────────────────────────►  │
  │                                            │
  │  drift_response { myPosition: 12.7, ... }  │
  │  ◄──────────────────────────────────────────┤
  │                                            │
  │  A 计算 delta = 12.5 - 12.7 = -0.2        │
  │  abs(0.2) < 0.5 → 不校正                  │
```

## 重连机制

```
连接断开
    │
    ▼
remoteStatus 变为 "已断开"
    │
    ▼
attempts = 1
    │ 延迟 2s
    ▼
attempts = 2
    │ 延迟 4s
    ▼
...
    │
    ▼
attempts = 5 (放弃)
    │
    ▼
toast 提示"重连失败，请重新加入"
```

**指数退避**：2s → 4s → 6s → 8s → 10s

---

## 信令服务器（`server/server.js`）

基于 [PeerJS 官方 Server](https://github.com/peers/peerjs-server) 库：

- 默认端口 9000，路径 `/`
- WebSocket 信令
- 监控连接/断开事件
- 支持优雅退出

**自建好处**：
- 不依赖 PeerJS 公共服务器（可能限流/挂掉）
- 可以加鉴权/限流
- 自己掌控日志
