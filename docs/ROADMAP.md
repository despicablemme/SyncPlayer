## 🔑 v1.0 工作清单

### P0 — 必做（不做不算 v1.0）

- [ ] **TURN 中继服务器** — 解决 ~15% NAT 穿透失败场景
- [ ] **信令服务器公网部署** — `server/server.js` 部署到公网 + HTTPS
- [ ] **客户端配置远程信令** — `app.js` 默认连自建，不走 PeerJS 公共
- [ ] **公网端到端测试** — 至少 2 个不同网络环境实测

### P1 — 应做

- [ ] **房间号 → 分享链接** — `https://domain/room/abc123` 一键加入
- [ ] **连接状态可视化** — 区分 P2P 直连 / TURN 中继 / 失败
- [ ] **错误友好提示** — 明确告诉用户发生了什么

### P2 — 锦上添花

- [ ] **移动端响应式适配**
- [ ] **视频两端文件校验**（防加载不同文件）
- [ ] **重连后状态恢复**（断线时对方的播放位置）

## 🛣️ v1.0 完成判定（Definition of Done）

v1.0 视为完成当且仅当：

- [ ] 两位测试者分别在**不同网络**（如家庭宽带 + 移动 4G）能成功建立连接
- [ ] 视频播放/暂停/seek 同步延迟 < 500ms
- [ ] 对称 NAT 网络下也能连上（走 TURN）
- [ ] 断线后 30 秒内能自动重连
- [ ] 公网地址 + HTTPS 部署完毕
- [ ] README 有清晰的部署说明
